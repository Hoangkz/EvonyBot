# Flow: Empire Depot

1. Mở Super Value Return và tìm/chọn đúng tab Empire Depot bằng ảnh tên.
2. Tìm đúng nút Claimable bằng crop cố định.
3. Chỉ DONE khi thấy đúng ảnh rương đã mở `chest_open`.
4. Không thấy Claimable nhưng rương chưa mở thì giữ PENDING.

Không dùng ảnh cả rương/panel làm điểm bấm và không bấm nút mua.
