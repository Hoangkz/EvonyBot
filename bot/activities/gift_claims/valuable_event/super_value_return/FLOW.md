# Flow: Super Value Return

1. Mở Super Value Return khi có badge đỏ ở vùng ngoài thành.
2. Duyệt toàn bộ badge đỏ trên carousel tab; Login Gifts luôn được mở kiểm tra một lần.
3. Với mỗi tab, chạy flow riêng: Empire Depot, Lucky Raffle, City Growth Plan hoặc Login Gifts.
4. Quét lại carousel theo hai hướng. Chỉ DONE khi badge đỏ đã hết.
5. Quay về màn thành.

Badge của tab khác không được dùng để kết luận tab hiện tại chưa xong.
